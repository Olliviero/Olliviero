# Olliviero Spaces

A "Spaces" dashboard for an AI video-clipping tool. It's a static site: open `index.html` in a browser, no build step needed.

- Spaces with a colour, video count and clip count
- Paste a link, upload or drag-and-drop a file, then pick a space and click "Generer klipp" (generate clips). This runs a simulated processing step with progress
- Search, filter tabs (All / Ready / Processing), create and delete spaces
- Data is saved in `localStorage`
- Responsive layout with a sliding sidebar on mobile
